# Visual reference notes

The live reference was captured and compared in the browser at 1363 × 936 in these states:

- supplied HOME reference with globe visible;
- live HOME desktop layout and navigation geometry;
- initial fully revealed page;
- menu-open viewport;
- scroll-complete viewport.

The reference uses a near-black blue gradient, white typography at multiple opacity levels, hairline geometry, sparse stars and deliberate glitch fragments. Reuse of the original person’s logo and contact details was intentionally excluded; the rebuild preserves the composition and interaction model with neutral sample identity content.
